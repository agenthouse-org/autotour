# webtour compatibility bridge

Webtour is integrated into AutoTour. Migrate to `@agenthouse-org/autotour-runtime`; see https://github.com/agenthouse-org/autotour/blob/main/docs/live-tours.md. Existing browser-facing names and preference keys remain unchanged. Deep imports and previously served `src/` paths must be migrated. This bridge is transitional; a retirement date has not yet been set.
